# 县域农产品直播带货选品质检发货售后平台（青溪农播平台）

围绕**同一条商品批次链路**，把农户申报、选品质检、直播排期、库存锁定、订单发货、售后处置与农户结算串成一体；
当出现「直播销量超预估、农户临时少供、检测报告过期、冷链车晚到、同批次坏果率升高、主播承诺与实际规格不一致」等情况时，
风险会沿批次链路自动联动，并支撑县域运营方复盘「哪些农户稳定、哪些品类适合直播、哪些售后原因影响复购」。

技术栈：Vue 3 + Vite（前端）｜ NestJS + TypeORM（后端）｜ PostgreSQL（数据库），`docker compose` 一键启动。

## 二、一键启动（Docker，推荐）

前置：安装 Docker 与 Docker Compose。

```bash
cd 171-a
docker compose up --build
```

启动后访问：

- 前端：<http://localhost:8080>
- 后端 API：<http://localhost:3000/api>
- PostgreSQL：localhost:5432（库 agri_platform / 用户 agri / 密码 agri）

后端首次启动会自动建表并写入演示数据（`SEED_ON_BOOT=true`）。重置数据：`docker compose down -v && docker compose up`。

## 三、本地开发启动（不用 Docker）

需要本机 PostgreSQL（或远程库），通过环境变量指定连接：

```bash
# 1. 数据库（示例：在已有 PostgreSQL 上）
createdb agri_platform

# 2. 后端（默认 127.0.0.1:5433/agri/agri，可用环境变量覆盖）
cd backend
npm install
DB_HOST=127.0.0.1 DB_PORT=5432 DB_USER=agri DB_PASSWORD=agri DB_NAME=agri_platform \
  npm run build && DB_PORT=5432 node dist/main.js
#   开发热更：npm run start:dev

# 3. 前端（新终端）
cd frontend
npm install
npm run dev          # http://localhost:5173 ，/api 自动代理到 127.0.0.1:3000
```

后端环境变量见 `backend/.env.example`（DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME/JWT_SECRET/SEED_ON_BOOT/CORS_ORIGIN）。

## 七、核心领域模型（批次链路）

- `farmers` 农户档案（稳定性评分、准时率、历史坏果率、复购率）
- `products` 商品申报（产地/采摘/规格/库存/检测报告/保质期/冷链要求/样品试吃/包装耐压/冷链可达城市/**承诺文本**）
- `batches` 直播批次（可供/锁定/已售、温区、本批坏果率、报告有效期、少供状态）——全链路挂在批次上
- `selections` 选品结论（履约评分六项明细 + 承诺差距 JSON + 决策备注）
- `live_sessions` / `live_items` 直播场次与排品（主播、脚本、试吃、价格、券、预估、**按稳定性折算的预售量**、实售、主播口径）
- `inventory_locks` 库存与包装材料锁定
- `orders` / `shipments` 订单与发货任务（发货仓、物流温区、售后承诺、冷链等待/延误）
- `after_sales` 六类售后（处置结果反写批次与农户）
- `settlements` 农户结算（售后扣减 + 品质违约金）
- `risk_alerts` 风险预警（报告过期/超卖/少供/冷链晚到/坏果率红线/承诺不符）
- `brand_notices` 县域公共品牌风险说明（草稿/发布）

## 八、风险引擎规则摘要（`backend/src/risk.service.ts`）

- **履约评分 100 分**：检测报告 20 / 采摘窗口 15 / 样品口感 15 / 包装耐压 15 / 冷链可达 15 / 农户交货稳定性 20；
  报告过期直接 0 分并建议暂缓上架。
- **承诺差距识别**：包甜×试吃低分、有机零农残×报告缺失/过期、次日达×冷链覆盖不足、坏果包赔×批次高坏果率、足斤足两×规格缺失。
- **建议预售量** = `批次余量 × max(0.5, 稳定性/100) × max(0.85, 1−坏果率/100)`。
- **预警阈值**：报告剩余 ≤7 天提醒 / 已过期高优；坏果率 ≥5% 中优、≥8% 高优红线并计 2% 违约金；冷链晚到 >120 分钟升级高优。
